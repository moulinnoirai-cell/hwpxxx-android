# PC 1.6.1 대비 Android 0.3.0 기능 점검

근거 기준: 이 브랜치의 소스·시험과 PC `moulinnoirai-cell/hwpxxx` 1.6.1(`docs/CHANGELOG-1.6.x.md`, `docs/KNOWN-ISSUES.md`). 이전 설명의 '완료'가 아니라 실제 시험 파일을 근거로 적습니다. 시험 이름은 `tests/` 기준입니다.

범례: **시험됨** = 이 저장소의 자동 시험이 해당 동작을 확인(로컬 Node/JVM/Chromium 실행 또는 CI). **작성·미실행** = 설치 APK 시나리오를 작성했지만 이 환경(KVM 없음)에서는 실행하지 못했고 해당 커밋의 Actions 결과로만 판단. **미구현** / **미검증**은 이유를 적습니다.

| 영역 | PC 1.6.1 | Android 0.3.0 | 근거·한계 |
| --- | --- | --- | --- |
| 글자 서식(굵게·기울임·밑줄·크기·색·자간·장평·형광펜) | 있음 | 한 문단 + **여러 문단 범위** | 시험됨: `editor-worker.test.mjs`(범위 서식·읽기 확인·실행 취소·저장 후 재열기, HWP/HWPX), `dex-ui.py` |
