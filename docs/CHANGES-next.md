# 다음 버전에 들어갈 변경 (0.3.3 이후, 아직 릴리스 전)

기준: Android 0.3.3. 버전 번호는 릴리스할 때 올립니다.

## 바뀐 것 (태블릿 실사용에서 보고된 문제)

- **HWPX 저장**: 저장(Ctrl+S)이 지금 파일의 확장자를 따릅니다. HWPX로 저장한 문서를 다시 저장할 때 ".hwp 확장자를 가진 파일을 선택해야 합니다"로 멈추던 것을 고쳤습니다. 새 문서의 첫 저장은 HWPX이고, 다른 이름으로 저장 창에 **파일 형식**(HWPX/HWP) 선택이 생겼습니다. 이름에 `.hwpx`/`.hwp`를 직접 쳐도 그 형식으로 저장합니다.
- **같은 이름으로 다른 이름으로 저장**: 이미 있는 파일 이름을 고르면 "이미 있어요. 바꿀까요?"를 묻고, 바꾸면 기존 파일을 백업한 뒤 덮어씁니다. 지금 연 문서 자신을 고르면 일반 저장과 같습니다. (PDF 등 내보내기는 예전처럼 다른 이름을 요구합니다.)
- **문자표**: 칸 크기를 고정하고 폭에 맞게 줄을 바꿔 세로 스크롤만으로 모든 문자를 고릅니다. 좁은 화면에서는 문자 영역 목록이 위로 갑니다.
- **화살표 키**: 도구 단추를 누른 뒤에도 화살표가 본문 캐럿을 움직입니다. Android가 쓰이지 않은 화살표 키로 초점을 편집기 밖으로 옮기지 못하게 했습니다.
- **숫자 뒤 한글 중복("21제주" → "2121제주")**: 삼성 키보드처럼 캐럿 앞 낱말을 다시 조합하는 입력기에서 앞 글자가 한 번 더 들어가던 것을 고쳤습니다. 되돌리기 한 번에 원래대로 돌아갑니다.
- **색을 여러 번 바꾼 글의 복사·붙여넣기**: 범위에 색을 주면 그 전에 캐럿에 예약해 둔 옛 색을 버립니다. Android 클립보드에서 내부 복사 표식이 빠져도, 붙일 글이 마지막 복사와 같으면 서식째 붙입니다.
- **색이 섞인 글에 색 일괄 적용**: 글자 색 단추를 형광펜처럼 나눴습니다. 본체는 막대에 보이는 색을 바로 적용하고(같은 색도 다시 적용), ▾는 팔레트(자주 쓰는 색, 검정, 다른 색...)를 엽니다.
- **서식 없는 글 붙여넣기의 되돌리기**: 선택을 덮어 붙인 뒤 되돌리기를 하면 지운 글이 돌아오지 않고 이후 되돌리기·다시 실행이 문서를 어긋나게 하던 것(내용 손실)을 고쳤습니다. 여러 줄 붙여넣기도 되돌리기 한 번입니다.
- **조합 중 단축키·클릭 (블루투스 키보드)**: 삼성 키보드는 띄어쓰기 전까지 낱말 전체를 조합하므로 조합 중 단축키가 흔합니다. 조합 중 Ctrl+Z를 누르면 앞 글이 지워지고 조합 글자가 겹치던 것("가간간")을 고쳤습니다. 단축키는 먼저 조합을 확정한 뒤 실행합니다. 조합 중 다른 곳을 누르면 조합을 그 자리에서 확정하고 누른 곳으로 캐럿을 옮깁니다(예전에는 원래 자리로 돌아갔음).

## 확인 범위

- 개발 기기에서 확인: 편집기 단위 시험 236개, 타입 검사, Android 셸 흉내 브라우저 시험 44개 중 43개(1개는 개발 기기에 시험용 글꼴 파일이 없어 실패, 코드와 무관), Chromium에서 문자표 배치, 도구 단추 뒤 초점, 다시 조합 시나리오 4가지("21제주", 음절 입력, 같은 숫자 두 번, "안녕"), 색 바꾸기·복사·붙여넣기, 섞인 색 일괄 적용, 붙여넣기 되돌리기, 조합 중 Ctrl+Z, 조합 중 다른 곳 클릭.
- 확인하지 않음: 삼성 키보드·하드웨어 키보드 실기기(브라우저 시험은 입력기 흉내), Android 초점 이동(네이티브 쪽 수정은 실기기에서만 드러남).
