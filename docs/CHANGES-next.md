# 다음 버전에 들어갈 변경 (0.3.3 이후, 아직 릴리스 전)

기준: Android 0.3.3. 버전 번호는 릴리스할 때 올립니다.

## 바뀐 것 (태블릿 실사용에서 보고된 문제)

- **HWPX 저장**: 저장(Ctrl+S)이 지금 파일의 확장자를 따릅니다. HWPX로 저장한 문서를 다시 저장할 때 ".hwp 확장자를 가진 파일을 선택해야 합니다"로 멈추던 것을 고쳤습니다. 새 문서의 첫 저장은 HWPX이고, 다른 이름으로 저장 창에 **파일 형식**(HWPX/HWP) 선택이 생겼습니다. 이름에 `.hwpx`/`.hwp`를 직접 쳐도 그 형식으로 저장합니다.
- **같은 이름으로 다른 이름으로 저장**: 이미 있는 파일 이름을 고르면 "이미 있어요. 바꿀까요?"를 묻고, 바꾸면 기존 파일을 백업한 뒤 덮어씁니다. 지금 연 문서 자신을 고르면 일반 저장과 같습니다. (PDF 등 내보내기는 예전처럼 다른 이름을 요구합니다.)
- **문자표**: 칸 크기를 고정하고 폭에 맞게 줄을 바꿔 세로 스크롤만으로 모든 문자를 고릅니다. 좁은 화면에서는 문자 영역 목록이 위로 갑니다.
- **화살표 키**: 도구 단추를 누른 뒤에도 화살표가 본문 캐럿을 움직입니다. Android가 쓰이지 않은 화살표 키로 초점을 편집기 밖으로 옮기지 못하게 했습니다.
- **숫자 뒤 한글 중복("21제주" → "2121제주")**: 삼성 키보드처럼 캐럿 앞 낱말을 다시 조합하는 입력기에서 앞 글자가 한 번 더 들어가던 것을 고쳤습니다. 되돌리기 한 번에 원래대로 돌아갑니다.
- **색을 여러 번 바꾼 글의 복사·붙여넣기**: 범위에 색을 주면 그 전에 캐럿에 예약해 둔 옛 색을 버립니다. Android 클립보드에서 내부 복사 표식이 빠져도, 붙일 글이 마지막 복사와 같으면 서식째 붙입니다.
- **색이 섞인 글에 색 일괄 적용**: 글자 색 단추를 형광펜처럼 나눴습니다. 본체는 막대에 보이는 색을 바로 적용하고(같은 색도 다시 적용), ▾는 팔레트(자주 쓰는 색, 검정, 다른 색...)를 엽니다.
- **서식 없는 글 붙여넣기의 되돌리기**: 선택을 덮어 붙인 뒤 되돌리기를 하면 지운 글이 돌아오지 않고 이후 되돌리기·다시 실행이 문서를 어긋나게 하던 것(내용 손실)을 고쳤습니다. 여러 줄 붙여넣기도 되돌리기 한 번입니다.
- **조합 중 단축키·클릭 (블루투스 키보드)**: 삼성 키보드는 띄어쓰기 전까지 낱말 전체를 조합하므로 조합 중 단축키가 흔합니다. 조합 중 Ctrl+Z를 누르면 앞 글이 지워지고 조합 글자가 겹치던 것("가간간")을 고쳤습니다. 단축키는 먼저 조합을 확정한 뒤 실행합니다. 조합 중 다른 곳을 누르면 조합을 그 자리에서 확정하고 누른 곳으로 캐럿을 옮깁니다(예전에는 원래 자리로 돌아갔음).
- **선택 없이 서식 단축키**: Ctrl+B를 두 번 누르면 꺼지고, 크기 키우기·줄이기는 누른 만큼 바뀝니다(예전에는 두 번째 Ctrl+B도 '켜기', 크기는 한 번만 바뀜). 예약한 서식은 도구 막대 단추에도 바로 보입니다.
- **되돌리기 단위**: 낱말 단위로 되돌립니다(입력 사이 1.5초 이내, 빈칸 뒤 새 낱말에서 끊음). 한글이 한 음절씩 되돌려지던 것을 고쳤습니다. 수정(덮어쓰기) 모드 입력은 예전 기준 그대로입니다.
- **같은 글 연속 입력**: 조합으로 확정한 글자와 같은 글이 조금 뒤에 다시 들어오면 버리던 것을, 확정 직후(0.3초 안) 브라우저의 중복 신호만 버리도록 좁혔습니다.
- **편집 잠금**: 편집 상태 오류로 문서가 잠기면 한글 조합 입력도 들어가지 않습니다.
- **메뉴·도구 상자의 붙이기**: 브라우저가 막는 경우 기기 클립보드를 읽어 붙입니다(서식 포함).
- **블록(선택 영역) 편집**
  - 블록 위에 글을 치거나(한글 조합 포함) Enter·Tab 을 누른 뒤 되돌리면 한 번에 원래 글로 돌아갑니다(예전에는 두 번, 여러 문단 블록은 첫 번째에 지운 상태가 보였음).
  - Tab 은 블록을 탭으로 바꿉니다(예전에는 블록을 남긴 채 캐럿 자리에 탭만 넣었음).
  - Shift 없이 ←·→ 를 누르면 블록의 시작·끝으로 캐럿이 갑니다(예전에는 한 칸 더 가 버렸음). ↑·↓ 는 시작·끝에서 한 줄 움직입니다.
  - Esc 는 블록만 풉니다(본문 블록에서 아무 일도 안 했음).
  - 일부만 진하게(기울임·밑줄·취소선)인 블록에 Ctrl+B 를 누르면 먼저 모두 진하게가 됩니다(예전에는 첫 글자만 보고 전부 꺼 버렸음).
  - 서식을 되돌리거나 다시 실행해도 블록이 남아, 다른 서식을 바로 줄 수 있습니다.
  - 두 번 누르면 낱말, 세 번 누르면 문단이 블록으로 잡힙니다.
- **표 칸 블록·셀 블록(F5)**
  - 셀 블록에서 Ctrl+B·I·U, 글자 크기 같은 서식 단축키가 블록 전체에 적용되고 블록도 유지됩니다(예전에는 블록이 풀리고 아무 칸에도 적용되지 않았음).
  - F5로 한 칸을 잡은 뒤 Shift+방향키로 블록을 넓힙니다(예전에는 잡은 칸만 옮겨 갔음).
  - 칸 안에서 일부만 진한 블록에 Ctrl+B 를 누르면 먼저 모두 진하게가 됩니다.
  - 칸 안 블록의 바꿔 쓰기 되돌리기 한 번, ←·→ 접기, Esc, 두 번 누르기 선택도 본문과 같이 동작합니다(Esc 를 한 번 더 누르면 예전처럼 표를 고릅니다).

## 확인 범위

- 개발 기기에서 확인: 편집기 단위 시험 244개, 입력·되돌리기·붙여넣기·서식 관련 기존 시험 100개 파일(실패 6건은 이번 수정 전에도 실패하던 것), 타입 검사, Android 셸 흉내 브라우저 시험 44개 중 43개(1개는 개발 기기에 시험용 글꼴 파일이 없어 실패, 코드와 무관), Chromium에서 문자표 배치, 도구 단추 뒤 초점, 다시 조합 시나리오 4가지("21제주", 음절 입력, 같은 숫자 두 번, "안녕"), 색 바꾸기·복사·붙여넣기, 섞인 색 일괄 적용, 붙여넣기 되돌리기, 조합 중 Ctrl+Z, 조합 중 다른 곳 클릭, 블록 편집 시나리오 27가지, 표 칸·셀 블록 시나리오 16가지.
- 확인하지 않음: 삼성 키보드·하드웨어 키보드 실기기(브라우저 시험은 입력기 흉내), Android 초점 이동(네이티브 쪽 수정은 실기기에서만 드러남).
