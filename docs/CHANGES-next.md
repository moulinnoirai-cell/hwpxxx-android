# 다음 버전에 들어갈 변경 (0.3.1 이후, 아직 릴리스 전)

기준: Android 0.3.1 (rhwp v0.9.0 고정은 그대로). 버전 번호(`versionName`·`versionCode`)는 릴리스할 때 올립니다.

## 바뀐 것

- **앱 이름**: 한눈글 → **hwpxxx** (런처, 미리보기 빌드는 `hwpxxx 미리보기`, 앱 안 제목·대화상자·인쇄 작업 이름).
- **문서 영역 세로 스크롤바**: 편집기 오른쪽에 항상 보이는 스크롤바를 두었습니다. 손잡이를 끌거나 빈 길을 눌러 이동합니다. 문서가 화면보다 짧으면 길만 보입니다. 끄는 동안 손잡이 옆에 지금 쪽(상태 표시줄과 같은 글)을 띄우고, 길 위에 메모가 달린 자리를 표시합니다.
- **한글 조합 중 글자 흔들림**: 조합 중인 글자가 깜빡일 때 위아래로 움직여 보이던 것을 고쳤습니다. 깜빡이는 표시(검은 상자의 흰 글자)를 본문 글자와 같은 기준선에 놓고, 본문처럼 상자 왼쪽에서 시작하며 장평을 따릅니다. 문서 종이는 어두운 테마에서도 흰색이라 상자 색은 그대로 둡니다.
- **글꼴 가져오기 보강**: 글꼴 묶음(`.ttc`)을 글꼴별로 나눠 가져옵니다. 표 정렬이 어긋난 오래된 글꼴을 바로잡아 보관하고, 옛 한글 인코딩으로만 적힌 글꼴 이름(완성형·조합형·맥 한글)을 읽습니다. 저장 한도는 64개·256MB(이전 128MB)입니다. 한컴 HY 글꼴(`HY*.TTF`, `H2*.TTF`)은 일반 TTF라 그대로 가져옵니다. 한컴 전용 `HFT`는 지원하지 않고, 폴더 가져오기에서 그 수를 알려 줍니다. 자세한 내용은 [글꼴 안내](ANDROID-FONTS.md).
- **릴리스 안전장치**: 서명 직전 소유자 승인(release Environment), 커밋 작성자 주소 검사(`identity` 작업과 pre-push 훅). 자세한 내용은 [릴리스 절차](RELEASE.md).

## 확인 범위

- 개발 기기(Termux)에서 확인: 편집기 단위 시험 216개, 타입 검사, `FontStoreTest` 177개 검사, Chromium에서 스크롤바 끌기·길 누르기·휠 연동·끄는 동안 쪽 표시·메모 자리 표시, 조합 글자와 본문 글자의 세로 위치 비교(4배 해상도에서 글자 아래 끝이 1px 차이, 이전 방식은 2px).
- 확인하지 않음: GitHub Actions 전체(빌드·에뮬레이터), 갤럭시 탭·DeX 실기기. 실제 HY 글꼴 파일과 Windows `.ttc` 파일은 개발 기기에 없어 합성한 글꼴로만 시험했습니다.
