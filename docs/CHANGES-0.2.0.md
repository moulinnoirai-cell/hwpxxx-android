### 서명과 기존 설치본

기존 0.1.2의 서명 키(인증서 `d7763191…b7f4c8`)는 받은 자료에 없습니다. 그래서 새 키로 서명했고, **설치된 0.1.2 위에 업데이트 설치가 되지 않습니다.** Android가 서명 불일치로 거부합니다. 0.1.2를 삭제한 뒤 설치해야 합니다.

- 삭제하면 앱 안에 저장된 즐겨찾기·읽던 위치·테마 설정이 지워집니다. 기기에 있는 HWP/HWPX 파일은 앱 밖에 있으므로 그대로 남습니다.
- 앞으로의 업데이트에는 새 키(`hwpxxx-android-signing/` 폴더, 저장소 밖)가 필요합니다. 따로 백업해 두세요.

## 재구축 과정에서 확인한 0.1.2 네이티브 차이

0.1.1 원본과 0.1.2 역컴파일 결과를 비교해 다음을 소스로 옮겼습니다.

| 항목 | 0.1.1 | 0.1.2 (역컴파일) → 0.2.0 |
|---|---|---|
| `delete` 작업 | 없음 | 있음. 파일 삭제 성공 후에만 목록에서 제거 |
| 첫 HWP 덮어쓰기 백업 | 없음 | `원본_백업_yyyyMMdd-HHmmss.hwp`. 백업 실패 시 저장 중단, 쓰기 실패 시 백업 제거 |
| HWPX 검사 | XML 안전 파싱 | 중앙 디렉터리 대조, manifest의 암호화 항목은 XML 검사 예외 |
| 저장 세션 잠금 | 무기한 | 2분 지난 세션은 버린 것으로 보고 새 저장 허용 |
| 새 이름 저장 | 복사 | 원자적 이동 먼저 시도, 안 되면 복사 후 해시 확인 |
| 화면 | 밝은 색 고정 | 어두운 테마 시스템 바, 글꼴 배율 반영, 키보드 높이만큼 inset |
| 오류 | 메시지만 | 메모리 부족 시 "원본은 변경하지 않았어요" 응답, 40만 자 넘는 요청에 응답 |
| `abortSave` | 세션 정리 | 0.1.2는 `true`만 반환하고 세션을 남김 → **0.1.1처럼 세션을 정리하도록 유지** |

역컴파일로 옮긴 코드는 동작을 재현한 것이며, 원본 소스와 줄 단위로 같다고 보장하지 않습니다.

## 남은 제한

- **설치:** 위 서명 문제로 기존 0.1.2를 지우고 설치해야 합니다.
- **폴더 선택기 모양:** 기능은 F02–F03을 갖췄지만, 화면은 0.1.2의 전체 화면 선택기 모양입니다. 디자인의 작은 팝업형 폴더 창으로 바꾸지는 않았습니다. PDF 저장도 디자인의 "이름 + 저장 위치" 팝업 대신 같은 선택기 아래쪽 이름 칸을 씁니다(F01 "같은 선택기").
- **검색 입력 초점 표시:** 디자인대로 검색창 테두리를 없앴습니다. 키보드로 이동할 때 검색창 초점 표시는 따로 없습니다(L01의 "초점 식별 유지"는 미반영).
- **작은 화면:** 안내 화면의 최소 높이는 디자인 값(540px)이라 아주 낮은 화면이나 가로 화면에서는 안내가 스크롤됩니다.
- **삭제:** 브리지와 확인 대화상자 코드는 남겼지만 메뉴에서 부를 길이 없습니다(L10).
- **PDF:** 기존처럼 페이지 그림(PNG) 기반이며 100페이지까지, 암호 문서는 지원하지 않습니다.
- **역컴파일 기반 코드:** 0.1.2 원본 소스가 아니라 동작을 재현한 것입니다.
