# Android 0.3.1 — 사용성·속도 개선

기준: Android 0.3.0 (rhwp v0.9.0 고정은 그대로).

## 바뀐 것

- **문서 열기 대화상자**: 검색 결과를 묶어서 그리고 200개씩 표시합니다. 찾는 동안 확인한 폴더·문서 수, 문서별 폴더·수정일·크기를 보여 줍니다. 모든 파일 접근이 꺼져 있으면 이유와 허용 단추를 보여 주고, 허용하고 돌아오면 자동으로 다시 찾습니다. 이름 입력 후 Enter로 첫 결과를 엽니다.
- **저장 위치 대화상자**: 문서의 폴더 → 마지막 저장 폴더 → Documents 순으로 시작합니다. 폴더의 기존 파일 이름을 보여 주고 같은 이름이면 닫지 않고 알려 주며 빈 이름을 제안합니다. 확장자를 빼고 입력하면 붙여 주고, 이름 칸에서 Enter로 저장합니다.
- **파일 앱·파일 선택으로 연 문서의 원본 저장**: 그 문서가 기기 저장공간의 파일임이 확인되면(경로 후보가 저장공간 안에 있고 형식·크기·SHA-256이 전달받은 내용과 같을 때) `Ctrl+S`가 원본에 저장합니다. 확인되지 않는 원본(다른 앱의 비공개 파일, 클라우드 문서)은 이전처럼 복사본으로 저장합니다.
- **한글 조합 글자 크기**: 시스템 글자 크기를 키운 기기에서 조합 중 글자가 본문보다 크게 보이던 것을 보정했습니다.
- **큰 문서 여는 시간과 편집 반응**: 첫 화면 전과 편집마다 모든 쪽의 레이어 트리를 내보내 읽던 호스트 글꼴 탐색을 없앴습니다. 문서의 글꼴 이름으로 가져온 글꼴을 바로 고르고, 전체 쪽 확인은 화면이 뜬 뒤 문서당 한 번 틈틈이 합니다.
- **글꼴 폴더 가져오기**: `Android · 글꼴` → **폴더에서 가져오기**로 폴더(하위 폴더 포함)의 TTF/OTF를 한 번에 가져옵니다.

## 측정 (폰, rhwp 0.9.0)

문서 열기(첫 화면까지, Node에서 편집기의 엔진 호출을 재현): 122쪽 3.5초 → 1.1초, 178쪽 6.7초 → 2.3초, 302쪽 10.0초 → 3.0초, 415쪽 43.7초 → 18.3초.
열기 대화상자(Chromium, 검색 완료 후 목록 표시까지): 문서 2,000개 7.1초 → 0.78초, 10,000개 201초 → 4.0초.
실제 화면 그리기와 글꼴 내려받기 시간은 포함하지 않은 값이며 기기 앱에서의 절대값은 다를 수 있습니다.

## 확인 범위

GitHub Actions의 빌드·JVM 시험·Chromium 시나리오·에뮬레이터(API 33) 스위트를 통과했습니다. 갤럭시 탭·DeX 실기기에서는 확인하지 않았습니다. 특히 삼성 '내 파일'에서 연 문서의 원본 저장, 조합 글자 크기, 폴더에서 글꼴 가져오기는 기기 확인이 필요합니다.
