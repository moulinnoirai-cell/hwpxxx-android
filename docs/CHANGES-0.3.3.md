# Android 0.3.3 — 조합 중 낱말 전체 깜빡임 수정

기준: Android 0.3.2 (rhwp v0.9.0 고정은 그대로). versionCode 8.

## 바뀐 것

- **한글 조합 중 낱말 전체 깜빡임**: 삼성 키보드처럼 띄어쓰기 전까지 낱말 전체를 조합 구간으로 두는 입력기에서, 그때까지 쓴 글자가 모두 깜빡이던 것을 고쳤습니다. 이제 지금 조합 중인 마지막 글자만 검은 상자로 표시하고, 앞 글자들은 본문 글자 그대로 보입니다.

## 확인 범위

- 개발 기기에서 확인: 편집기 단위 시험 222개, 타입 검사, Chromium에서 여러 글자 조합 시 상자가 마지막 글자만 덮고 한 글자씩 오른쪽으로 옮겨 가는지.
- GitHub Actions의 빌드·시험·에뮬레이터(API 33) 스위트.
- 확인하지 않음: 삼성 키보드 실기기(Chromium 시험은 입력기 흉내).
