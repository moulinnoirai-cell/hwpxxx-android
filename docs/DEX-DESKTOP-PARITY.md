# DeX 데스크톱 편집기

목표 버전은 Hwpxxx 데스크톱 1.6.1입니다. 한글 2024의 전체 기능을 새로 만드는 범위는 아닙니다.

## 편집기 공유

Android 전용 도구 모음을 늘리는 대신 데스크톱의 실제 `rhwp-studio` 화면·명령·선택·키보드·툴팁 코드를 빌드합니다. 데스크톱의 upstream 커밋과 11개 패치를 고정하고, Android 호스트 연결 패치를 그 뒤에 적용합니다. Android의 WASM은 별도로 검증한 MVP 빌드를 사용합니다.

명령 등록부에는 168개 ID가 있습니다. 편집 17, 입력 26, 도구 1, 표 27, 쪽 25, 메모 5, 하이퍼링크 3, 서식 36, 보기 14, 파일 14입니다. 이는 공유하는 구현의 목록이며, 168개 동작 전부가 실물 DeX에서 검증됐다는 뜻은 아닙니다.

## Android 사용

- `Ctrl+O`: 기기 문서 목록, Android 파일 선택 또는 연결한 프로젝트 폴더에서 열기.
- `Ctrl+S`: 열린 기기 문서에 저장. 외부에서 파일이 바뀌면 덮어쓰기를 거절합니다.
- 다른 이름으로 저장: 새 복사본 생성. 연결 폴더·선택한 외부 파일·복구 문서의 원본은 변경하지 않습니다.
- `Android · 글꼴`: 내려받은 TTF/OTF 가져오기와 삭제. 글꼴은 앱의 비공개 저장공간에 보관하고 다시 실행해도 유지합니다. 등록한 글꼴은 데스크톱 글꼴 선택기와 실제 문서 렌더러에 공급합니다.
- 파일 앱의 **연결 프로그램 / 공유**에서 HWP·HWPX·HML을 열 수 있습니다. 이미 편집 중이면 저장·버리기·취소 확인을 거칩니다.
- 시스템 클립보드의 글자·서식·이미지를 편집기에 연결합니다. 이미지 바이트는 앱의 비공개 임시 파일을 통해 전달합니다.
- 최근 문서: 기기 문서와 읽기 권한을 보관할 수 있는 선택 파일은 권한을 확인하고 다시 엽니다. 임시 공유 파일이나 권한이 만료된 파일은 다시 선택합니다.
- 문서 이력: 일반 문서의 스냅샷은 기기에 암호화해 보관합니다. **암호 문서의 이력 스냅샷은 앱 세션의 메모리에만 보관**하며 화면에 이를 표시합니다.
- Android 뒤로 가기: 열린 호스트 대화상자를 닫거나, 문서의 저장·버리기·취소 확인을 거칩니다.

글꼴을 문서에 적용해도 원본 글꼴 파일을 다른 기기에 자동 설치하거나 문서 안에 자동 삽입하지는 않습니다. 같은 글꼴로 다른 기기에서 편집하려면 그 기기에도 해당 글꼴이 필요합니다.

## 저장과 복구

네이티브 경로 검증·크기 제한·원자적 저장·원본 해시 확인을 유지합니다. 저장 완료 응답을 받은 뒤에만 편집기가 저장 완료 상태로 바뀝니다. 내보낸 문서는 쓰기 전에 다시 열어 내용과 서식을 확인하며, 엔진이 내용 손실을 보고하면 저장을 멈춥니다.

복구 자료는 앱 비공개 저장소를 사용합니다. 암호 문서의 비밀번호를 설정·로그·메타데이터에 저장하지 않습니다. 암호 복구 자료도 암호화된 문서 바이트여야 하며, 비밀번호 없이 평문으로 우회하지 않습니다.

문서를 바꾼 뒤 이전 문서의 저장이 늦게 완료돼도 현재 문서의 이름·저장 대상·저장 상태를 바꾸지 않도록 처리합니다. PDF/인쇄는 등록한 글꼴을 사용하는 실제 Canvas 렌더러에서 한 쪽씩 생성합니다.

기존 문서 제한은 32MiB, 저장 재열기 검증은 최대 500쪽, 한 번의 PDF/인쇄는 최대 100쪽입니다. 머리말·꼬리말 필드가 있는 문서는 별도 HWPX 의미 검증도 수행합니다. 이 검증의 구역 XML 합계는 최대 64MiB이고, 필드가 든 머리말·꼬리말 문단은 최대 4096자·파일 이름 필드 8개입니다. 확인 한도를 넘으면 원본을 변경하지 않고 저장을 거절합니다. 글꼴은 파일당 16MiB, 최대 64개·총 128MiB입니다. 시스템 클립보드의 글자와 HTML 합계는 UTF-8 기준 256KiB까지입니다.

외부 파일 제공자의 읽기는 25초 제한과 제한된 작업자 풀을 사용합니다. 제공자가 응답하지 않아도 이후 저장 작업까지 계속 막지 않도록 처리합니다. 같은 외부 파일을 다시 열면 기존 연결 ID를 재사용하며, 한 세션에서 서로 다른 파일 연결은 최대 1024개입니다.

데스크톱과 동일하게 외부 웹 요청·외부 링크·새 창은 차단합니다. Android 앱에 인터넷 권한을 추가하지 않습니다.

## 검증 구분

`tests/studio-ui.py`는 실제 생산용 Studio 번들과 WASM을 Chromium에서 실행합니다. Android 파일 경계는 임시 문서 사본과 가짜 `OfflineNative`로 시험합니다. 이것을 Android 기기·Samsung DeX 시험 결과로 계산하지 않습니다.

`tests/android-font-renderer.py`는 실제 Canvas2D/CanvasKit 렌더러가 등록한 SFNT 바이트를 사용하는지 픽셀과 글자 폭으로 비교합니다. 파일·글꼴 저장소는 별도 JVM 시험으로 검사합니다.

최종 Samsung DeX 확인에는 실제 기기의 Samsung IME, 블루투스 키보드·마우스, 우클릭·드래그·휠, 창 크기 변경과 시스템 인쇄를 포함해야 합니다. 이 클라우드 환경에는 해당 하드웨어가 없습니다.
