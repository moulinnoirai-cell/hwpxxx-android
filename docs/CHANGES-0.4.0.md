# Android 0.4.0 — rhwp v0.9.1 기준선과 본가 수준 보강

기준: Android 0.3.4. 엔진·편집기를 rhwp v0.9.0 → **v0.9.1**(981ce66)로 옮겼습니다. versionCode 10.

## 엔진·편집기 (rhwp v0.9.1)

- 본가 v0.9.1의 조판·저장 보정(중첩 표, 셀 안 그림·도형, 머리말·꼬리말·바탕쪽, 수식·기호 글꼴), HTML 표 붙여넣기, 번호·글머리표 글자모양 보존, 작은 화면 대화창 개선이 들어왔습니다.
- hwpxxx 패치는 v0.9.1 위로 다시 만들었습니다. 본가가 같은 기능을 갖게 된 곳(글꼴 이름 메모, 글꼴 대체)은 본가 구현을 씁니다.

## 새로 된 것

- **PDF 가져오기**: 파일 열기·기기 문서 목록·다른 앱에서 공유한 PDF를 편집 가능한 문서로 가져옵니다. PDF 원본은 바꾸지 않고, 저장은 새 HWPX/HWP 파일로 합니다.
- **HWP 3.0 문서 열기**: 예전 한글(3.0) 문서를 엽니다. 원본은 덮어쓰지 않으며, 처음 저장할 때 새 HWP 파일을 고르고 이후에는 그 파일에 저장합니다.
- **터치·펜 편집**
  - 길게 누르면 낱말이 선택되고 시작·끝 손잡이가 나타납니다. 손잡이를 끌어 범위를 넓힙니다. 한 손가락 세로 쓸기는 그대로 스크롤입니다.
  - 표 안에서 손잡이를 끌면 칸 블록이 잡힙니다.
  - 그림·도형을 눌러 고르고, 끌어서 옮기거나 핸들로 크기를 바꿉니다.
  - 눈금자의 들여쓰기·여백 표시를 손가락·펜으로 끌 수 있습니다.
  - 펜은 마우스처럼 끌어 선택합니다.
  - 한글 조합 중에 화면을 누르면 마우스 클릭과 같이 조합을 확정합니다.
- **인쇄**
  - 인쇄 창에서 고른 쪽 범위만 출력합니다(예전에는 전체 쪽).
  - 쪽을 한 장씩 그려 보내므로 100쪽이 넘는 문서도 인쇄할 수 있습니다.
  - 프린터 해상도에 맞춰 그립니다.

## 고친 것

- **인쇄에서 가져온 글꼴**: 인쇄·PDF 저장이 가져온(등록한) 글꼴 대신 대체 글꼴로 그려지던 것을 고쳤습니다. 0.9.0 때부터 있던 문제로, 시험이 잡지 못했습니다(시험 기준도 바로잡음).

## 알려진 한계

- 인쇄·PDF 저장은 여전히 그림(PNG) 방식이라 PDF에서 글자를 선택·검색할 수 없습니다.
- 터치의 표 칸 블록·개체 이동·눈금자는 브라우저 시험으로 확인하지 못해 실기기 확인이 필요합니다.
