# Android 0.4.1 — 빈 탭 정리와 그림 든 HWPX 저장·열기

기준: Android 0.4.0. 엔진·편집기는 그대로 rhwp v0.9.1입니다. versionCode 11.

## 고친 점

- 빈 "새 문서" 탭에서 문서를 열면 탭이 두 개(빈 새 문서 + 연 문서)가 되던 문제를 고쳤습니다. 지금 탭이 아무것도 입력하지 않은 빈 새 문서이면 열기(`Ctrl+O`, 탭 줄의 열기 단추), 최근 문서, 파일 앱에서 전달받은 문서를 그 탭에서 엽니다. 앱을 처음 켜면서 파일 앱으로 문서를 열 때도 같습니다. 입력한 내용이 있거나 파일·암호가 있는 문서에서는 지금처럼 새 탭에서 엽니다. 새 문서(`Ctrl+T`, `+`)는 계속 새 탭을 만듭니다.
- 그림이 든 HWP 문서(예: 로고가 있는 기안문)를 HWPX로 저장하면 저장이 거부되고, rhwp로 만든 같은 종류의 HWPX는 열리지 않던 문제를 고쳤습니다. rhwp(앱 엔진 포함)는 HWP의 그림을 HWPX로 옮길 때 압축 자료 뒤에 몇 바이트를 남깁니다. 앱의 압축 검사가 이를 거부했습니다. 이제 그 바이트만 잘라 낸 사본을 검사해 열고, 저장·복구 자료는 잘라 낸 깨끗한 파일로 씁니다. 원본 파일은 바꾸지 않습니다. 다른 압축 이상(목록 불일치, CRC 오류, 16바이트를 넘는 잔여 등)은 지금처럼 거부합니다.
