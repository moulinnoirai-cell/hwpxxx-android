# hwpxxx — 완전 오프라인 UI 확정 명세

작성·검토 반영일: 2026-10-16 (한국시간, 기존 작업일 기준)
대상: com.hwpviewer.hwp 1.0.6 분석을 바탕으로 한 개인용 개편안
상태: 시안 확정 후 별도 Android 앱 ‘오프라인 한글 0.1.0’의 소스·설치 APK 제작. 원본 APK는 수정하지 않았으며 새 앱의 실기기 설치 시험은 미수행.

## 현재 이름·로고 반영 — 0.1.1

확정 프로그램 이름은 hwpxxx이며 사용자가 첨부한 H 수채화 로고를 런처의 일반·적응형 아이콘과 앱 정보 화면에 적용했다. 기존 0.1.0과 같은 패키지·서명을 유지하고 버전 코드를 2로 올렸다. 이름·로고 및 서명/패키지 검증을 완료했으며 이전의 실기기 시험 미수행 상태는 유지한다. 아래 0.1.0 설명은 기능 구현 이력이다.

## 0. 실제 앱 제작 반영 — 0.1.0

사용자의 “이대로 코딩 제작” 요청에 따라 Android 앱을 새로 작성했다. 패키지는 `kr.offline.hwp`, Android 11 이상, 공식 rhwp 0.8.7·로컬 JS/WASM/아이콘/폰트를 사용한다. 의심 APK의 Android 코드·광고·관리 SDK는 재사용하지 않았다. APK 빌드·개인 서명·서명 검증을 완료했다. 아래 1~9절의 시안 설명은 디자인 근거이며 실제 구현 범위는 이 절과 제공 소스의 README가 우선한다.

| 실제 구현 | 검증 범위 |
|---|---|
| 실제 문서 검색·파일 권한 설정·썸네일 | Android 코드 작성, 브리지는 브라우저 시험 대역 사용. 실제 문서 엔진은 실행 |
| 문서함 검색·보기/정렬·별·상시 바·길게 누르기 | Chromium 133에서 실제 UI 시험 |

| HWP/HWPX 열람·본문/표 셀 글자 편집 | 실제 WASM으로 문서 파싱·편집·재열기 시험 |
| 문단 분할/병합·여러 문단 붙여넣기·이모지·실행 취소 | 본문 및 표 셀의 실제 엔진 시험 |

| HWP/HWPX 재검증·원본 해시 충돌·원자적 교체 | 실제 Java/JVM 파일 시험. Android 저장장치 시험은 미수행 |
| PDF 로컬 출력 | SVG→PNG 생성/전송 시험. Android PdfDocument 코드 빌드, 실제 PDF 출력은 미시험 |

초기 버전의 차이·한계:

- PDF는 페이지 이미지 방식이며 PDF 글자 검색/선택을 지원하지 않는다.
- 다른 이름/PDF 저장에서 기존 파일 덮어쓰기는 차단하고 이름/경로 변경을 요구한다. 일반 저장만 원본 변경을 확인 후 안전하게 덮어쓴다.
- 문단 글자·줄 나눔 편집은 연결했다. 별도 서식·글꼴·표 구조 편집 도구와 교차 문단 전체 선택은 제공하지 않는다.
- 문서/저장 결과 32MiB, HWPX 해제 누적 128MiB, 문서 500페이지, PDF 100페이지 한도다.
- 암호 입력 문서와 강제 종료 후 편집 초안 복구는 제공하지 않는다. 앱 복귀 시 권한/볼륨은 다시 확인하지만 파일 변경의 증분 반영은 새로고침을 사용한다.
- Android 기기/에뮬레이터에 실제 설치·실행하지 않았다. 시스템 WebView·권한·IME·터치·SD 분리·실제 PDF·TalkBack·큰 글씨·다양한 서식 호환성은 남은 검증이다.
- 원본 의심 APK의 F12/F13을 패치한 결과물이 아니다. 해당 저장 문제를 고려한 별도 앱 구현이다.

## 1. 이번 반영의 범위

검토 중이던 사항을 아래 확정안으로 통합했다. 앞선 명세의 파일 열기, 왼쪽 문서 다시 찾기, 설정의 문서 자동 찾기, 자체 작은창(팝업), 사본 저장 중심 구성은 이 명세로 대체한다.

| 영역 | 확정안 | 시안 반영 |
|---|---|---|
| 문서함 상단 | 문서함 제목 + 오른쪽 아이콘·새로고침 | 완료 |
| 불필요 항목 | 부제, 파일 열기, 전체/HWP/HWPX 필터 제거 | 완료 |
| 검색 | 포커스 테두리 없음, X 24px·터치 영역 48px | 완료 |
| 파일 목록 | 썸네일·두 줄 이름·폴더, 길게 누르기 메뉴, 상시 스크롤바 | 완료 |
| 즐겨찾기 | 별 즉시 채움·해제, 화면 팝업 없음, 목록 즉시 반영 | 완료 |
| 새로고침 | 목록·미리보기 통합, 점진 표시·중지, 완료/중지 팝업 없음 | 예시 데이터로 구현 |
| 권한 | 미허용 사용자에게 새로고침 일회 강조 → 설명 그림 → Android 설정 | 모의 설정 화면으로 구현 |
| 설정 | 테마, 로컬 사용 방법, 앱 정보·라이선스 | 완료 |
| 자체 작은창 | 기능·설정·버튼·설명·권한 흐름 모두 제거 | 완료 |
| 열람 상단 | 한 줄 뒤로·문서 이름/페이지 위치·오른쪽 연필 아이콘 | 완료 |
| 열람 상태 문구 | 읽기 모드/편집 중, 원본·사본 안내 삭제 | 완료 |
| 편집 상단 | 취소 / 저장 / 다른 이름으로 저장, 같은 크기·입력 시 페이드 | 완료 |
| 저장 흐름 | 변경 때만 저장 활성화, 저장 예/아니오 확인, 다른 이름 저장은 항상 활성화 | 예시 문서로 구현 |
| 다른 이름/PDF 저장 | 이름·폴더 선택. PDF는 문서함 길게 누르기 메뉴로 이동 | 모의 폴더로 구현 |
| 파일 이동 | 폴더 목록·하위 탐색·검색·정렬·새 폴더 만들기·여기로 이동 | 예시 데이터로 구현 |
| 읽기 집중 | 상단 페이드와 함께 상단 여백 축소, 하단 바 없음 | 완료 |
| 상태 기억 | 읽던 위치·배율, 검색·정렬·보기, 즐겨찾기·테마 | 시안 내부 로컬 저장 |

시안의 권한 허용·문서 편집·저장은 예시 데이터의 상태 변화다. 실제 Android 권한을 얻거나 사용자 파일에 기록하지 않으며 HWP/HWPX 파싱·PDF 생성도 수행하지 않는다. 브라우저 저장이 허용되는 환경에서만 시안의 상태가 다음 실행까지 유지된다. 실제 앱은 앱 전용 로컬 저장소를 사용해야 한다.

## 2. 제품 원칙

- 사용자가 문서를 찾고 읽고 수정해 저장하는 과정이 우선이다. 제거한 기능의 빈 영역·비활성 메뉴를 남기지 않는다.
- 인터넷 송신·수신, 원격 자산·명령·업데이트, 광고·추적·푸시, 외부 앱 실행·공유·업로드를 제거한다. 온라인 예외 설정은 두지 않는다.
- HWP/HWPX는 통합 목록에 표시한다. 파일 이름·확장자는 보존하며 형식별 필터를 요구하지 않는다.
- 기기 내 문서 자동 검색과 썸네일을 유지한다. 파일 접근 권한은 문서 자동 모아보기의 전제다. OS가 접근을 금지하는 위치까지 전부 찾는다고 안내하지 않는다.
- 앱 자체 팝업·PiP·오버레이 기능과 안내는 모두 제외한다. 오버레이·배터리 예외·관련 서비스도 제거 대상이다.
- 설치 가능한 앱의 완료 판정은 화면 시안 검증과 구분한다. 실제 엔진·안전한 저장·오프라인 시험을 통과하기 전에는 기능 완료로 표시하지 않는다.

## 3. 문서함·즐겨찾기

상단은 제목과 오른쪽의 새로고침 아이콘·텍스트로 정리한다. 기존 파일 열기 위치를 사용한다. “이 기기에 저장된 한글 문서” 부제, 파일 열기 버튼, 형식 필터는 삭제한다.

검색은 파일 이름을 대상으로 한다. 앞뒤 공백을 제거해 비교하고 대소문자를 구분하지 않는다. 입력 중 입력창을 다시 만들지 않아 포커스·키보드를 유지한다. 입력 시 오른쪽 X를 표시한다. 검색창에는 클릭·키보드 입력 시에도 테두리·외곽선을 표시하지 않는다. 다른 버튼과 입력 항목의 접근성 포커스는 유지한다.

목록 도구는 결과 개수, 최근 수정순/이름순/큰 파일순, 미리보기/목록 전환 버튼 하나다. 기본은 미리보기이며 이때 버튼은 목록 아이콘을 보여준다. 목록에서는 미리보기 아이콘을 보여준다. 누를 때마다 보기와 아이콘·접근성 이름을 함께 바꾸고 설정을 로컬에 기억한다. 검색·정렬·보기·스크롤을 문서에서 돌아올 때 유지한다. 테마·보기·정렬·즐겨찾기는 재실행 후에도 기기 안에서 기억한다.

카드에는 첫 페이지 미리보기, 파일 이름, 폴더, 확장자·용량, 더보기와 별을 둔다. 긴 이름은 최대 두 줄이며 확장자를 별도로 식별할 수 있게 한다. 문서를 길게 누르거나 더보기에서 파일 정보를 선택해 전체 이름과 위치를 확인한다. 같은 이름은 폴더로 구분한다. 별은 문서를 열지 않고 즉시 채워지거나 비워진다. 즐겨찾기 추가·해제 안내 팝업/토스트는 표시하지 않는다. 스크린리더에는 결과만 조용히 알린다. 화면을 가리는 안내 영역이나 입력을 가로채는 레이어를 만들지 않아 다음 별·하단 즐겨찾기 메뉴를 곧바로 누를 수 있어야 한다. 즐겨찾기 해제 시 해당 목록에서도 즉시 제외한다.

문서 검색 결과를 먼저 표시하고 미리보기는 순서대로 생성한다. 작업 중 검색·정렬·문서 열기를 막지 않는다. 새로고침에는 진행 상태와 중지를 제공한다. 중지해도 기존 목록·생성된 미리보기·사용자 문서는 보존한다. 새로고침 완료·중지 후 하단 팝업/토스트는 표시하지 않는다. 진행 영역을 닫고 목록만 유지한다. 화면읽기에는 완료 상태를 알릴 수 있다. 무한 반복 애니메이션과 고정 시간의 가짜 진행률을 실제 앱에 넣지 않는다.

### 문서함의 상시 스크롤바

오른쪽에 회색의 얇은 세로 스크롤바를 항상 표시한다. 카드 밖에 별도 여백을 확보해 파일명·별·더보기와 겹치지 않게 한다. 레일과 손잡이는 둥근 끝을 사용하고, 밝고 어두운 화면에서 모두 구분되도록 한다. 문서함에서는 페이드아웃하지 않는다.

손잡이 길이는 화면에 보이는 목록의 비율을 나타내고 위치는 실제 스크롤과 연결한다. 손잡이를 끌거나 문서 목록을 일반 스크롤해 이동할 수 있다. 한 화면에 모두 들어오면 손잡이는 전체 구간을 나타내고 드래그를 비활성화한다. 검색·정렬·보기 전환·화면 크기 변경 후 길이와 위치를 갱신한다. 이는 문서 열람 화면의 빠른 페이지 탐색 바와 구분한다.

### 문서 길게 누르기 메뉴

첨부한 파일 관리 메뉴를 참고하되 아래 네 항목만 표시한다. 메뉴에 선택한 파일 이름을 보여주고 작은 화면 안에 들어오도록 위치를 보정한다.

| 항목 | 동작 |
|---|---|
| 이름 변경 | 원래 폴더 안에서 파일 이름을 변경. 확장자 유지, 빈 값·잘못된 이름·중복 검사 |
| 파일 이동 | 현재 위치를 확인하고 이동할 로컬 폴더 선택. 파일 이름을 유지한 채 위치 변경 |
| PDF 저장 | 선택 문서를 대상으로 이름·로컬 폴더 지정. 완료/취소 후 문서함 유지 |
| 파일 정보 | 전체 이름·폴더·용량·수정일 |

공유·클립보드·다른 앱/새 창에서 열기·홈 화면 추가·보안 폴더 이동 등은 메뉴에 넣지 않는다. 파일 이동은 이 문서 메뉴에서 제공하며 별도 일괄 이동·복사·삭제 도구 모음은 추가하지 않는다. 즐겨찾기 항목은 이 팝업에서 제거하고 카드의 별 버튼으로만 조작한다. 메뉴 호출은 문서 열기와 구분하며, 길게 누른 손을 뗄 때 문서가 열리지 않도록 한다. 스크롤·드래그는 길게 누르기를 취소한다. 더보기 버튼·마우스 오른쪽 클릭·키보드 메뉴 키/Shift+F10으로도 같은 항목에 접근할 수 있다.

### 파일 이동 — 폴더 탐색과 새 폴더 만들기

문서 작업 → 파일 이동은 첨부한 Android 폴더 선택 화면처럼 탐색형으로 구성한다. 이전의 경로 드롭다운을 이 화면으로 대체한다.

- 상단: 폴더 선택 제목, 폴더 검색, 새 폴더 만들기 아이콘.
- 현재 위치: 내장 저장공간/사용 가능한 로컬 저장공간 선택, 상위 폴더 버튼과 경로 표시.
- 목록: 노란 폴더 아이콘, 폴더 이름·날짜·항목 수. 폴더를 누르면 하위 목록으로 들어간다. 파일은 목적지 선택 목록에 표시하지 않는다.
- 정렬: 이름순/날짜순과 오름차순/내림차순. 기본 예시는 날짜 내림차순이다.
- 하단: 이동할 파일 이름, 취소 / 여기로 이동. 목록이 길어도 하단 동작은 계속 표시한다.

처음에는 저장공간의 폴더 목록을 보여준다. 이동할 경로를 명시적으로 선택하기 전과 원래 폴더에서는 여기로 이동을 비활성화한다. 다른 유효한 폴더에 들어가면 해당 위치를 목적지로 사용한다. 폴더가 비어 있어도 이동할 수 있다. 깊은 경로는 중간을 줄여 표시하고 상위 버튼·경로 버튼으로 돌아갈 수 있게 한다. 키보드 Escape는 생성 중인 폼을 닫거나 한 단계 위로 이동하며, 최상위에서는 선택을 취소한다.

폴더 검색은 현재 위치의 하위 폴더 이름을 대상으로 하며 입력 위치와 키보드 포커스를 유지한다. 결과가 없거나 하위 폴더가 비어 있는 경우를 구분한다. 저장공간 전환 시에는 실제 연결돼 있고 접근 가능한 로컬 저장공간만 표시한다. 시안의 SD 카드 등은 예시 데이터다.

새 폴더 아이콘을 누르면 현재 경로에 만들 폴더 이름을 입력한다. 취소 / 만들기를 제공하며 빈 이름, 경로 구분자·제어 문자, . 및 .., 이름 길이, 같은 이름의 기존 폴더를 검사한다. 생성 성공 후 그 폴더 안으로 들어가 여기로 이동을 바로 누를 수 있게 한다. 생성 중에는 이동과 중복 생성 동작을 비활성화한다. 폴더 생성 취소는 입력을 닫으며 파일을 이동하지 않는다. 생성이 완료된 폴더는 이후 파일 이동을 취소해도 유지한다.

여기로 이동을 누르면 파일 이름·확장자는 유지하고 위치만 변경한다. 대상에 같은 이름의 파일이 있으면 “같은 이름의 파일이 있어요. 다른 폴더를 선택해 주세요.”를 해당 화면에 표시하며 두 파일을 보존한다. 취소하면 원래 파일 위치·내용은 바뀌지 않는다. 이동 후 경로·파일 정보를 갱신하고 즐겨찾기·읽던 위치·미리보기를 같은 문서로 연결한다. 완료 토스트는 추가하지 않는다.

시안은 예시 폴더 목록·하위 탐색·검색·정렬·생성 및 예시 문서 이동을 구현했다. 실제 Android 저장소 탐색·폴더 생성·파일 이동은 수행하지 않는다. 실제 앱에서는 로컬 디렉터리와 권한·쓰기 가능 여부를 연결하고, 저장공간 부족·읽기 전용·SD 분리 등 실패 이유를 구분해야 한다. 같은 파일시스템에서는 가능한 안전한 경로 변경을 사용하며, 저장소 간 이동은 대상 쓰기·검증이 성공한 뒤 원래 항목을 정리한다. 클라우드·외부 앱 위임은 제공하지 않는다.

## 4. 파일 접근 안내

첫 실행에 설명을 강제로 겹쳐 띄우지 않는다. 미허용 상태에서는 문서함의 새로고침을 한 번만 부드럽게 강조한다. 누르면 짧은 설명과 그림을 보여준다.

그림: 여러 폴더의 한글 문서 → 파일 접근 허용 → 미리보기와 함께 문서함에 모임.

설명: “기기에 있는 한글 문서를 자동으로 찾아 모아보려면 파일 접근 허용이 필요합니다. 문서 목록과 미리보기는 기기 안에서 처리합니다.”

행동: 나중에 / 파일 접근 허용.

실제 Android에서는 지원 OS의 전체 파일 접근 설정 화면으로 연결하고, 복귀 시 실제 허용 상태를 다시 확인한다. 앱 버튼만으로 허용됐다고 처리하지 않는다. 허용 후에는 자동 새로고침한다. 거절·뒤로가기는 존중하며 반복 팝업·반복 강조를 하지 않는다. 다시 새로고침을 누르면 같은 설명에 접근할 수 있다.

현재 전체 문서 검색 구조에서는 이 권한이 필요하므로 미허용 시 자동 문서함을 사용할 수 없음을 설명한다. 삭제하기로 한 개별 파일 열기 버튼은 대체 기능으로 다시 넣지 않는다. 설정에도 문서 자동 찾기 권한 버튼을 두지 않는다. 권한 철회·SD 카드 분리는 재확인하고, 미저장 편집 내용이 있으면 메모리에서 보존해 다른 로컬 위치에 저장할 수 있도록 한다.

## 5. 문서 열람과 상단 여백

열람 상단은 뒤로, 문서 이름/페이지 위치, 오른쪽 끝의 작은 연필 아이콘을 한 줄로 구성한다. 편집 글자는 표시하지 않고 접근성 이름은 문서 편집으로 제공한다. 아이콘은 약 22px로 작게 표시하되 누르는 영역은 48px를 유지한다. 긴 문서 이름은 두 줄까지 표시하고 파일 정보에서 전체 이름을 확인한다.

기존 편집/PDF 저장의 큰 버튼 줄, 하단 바, 보기 배율 버튼은 제거한다. PDF 저장은 문서함의 길게 누르기/더보기 메뉴에 배치한다.

읽기 중 본문 한 번 터치로 상단 전체를 약 180ms 동안 페이드아웃한다. 투명하게만 바꾸고 빈 상단 공간을 남기는 방식은 사용하지 않는다. 숨기면 도구 모음 높이만큼의 예약 여백을 없애고 문서는 기본 여백 16px부터 표시한다. 다시 누르면 상단과 필요한 여백을 복원한다. 문서가 스크롤된 상태에서는 여백 차이만큼 스크롤 위치를 보정하고, 시작/끝에서는 유효한 범위로 제한한다. 숨긴 메뉴는 클릭·키보드 포커스에서 제외한다. 편집 메뉴에도 같은 여백 처리를 적용한다.

읽던 위치 저장에는 상단 표시 상태에 따른 여백도 함께 고려해 재열람 때 같은 본문 위치를 복원한다. 글자가 커지거나 파일명 때문에 도구 모음 높이가 바뀌면 실제 높이를 다시 계산한다. 문서 서식·배율은 메뉴 숨김으로 변경하지 않는다. 첫 열람의 사용 안내도 본문을 덮는 팝업으로 표시하지 않는다. 동작 감소 설정에서는 페이드를 생략한다.

## 6. 편집·저장

편집 진입 후 상단은 취소 / 저장 / 다른 이름으로 저장 세 버튼만 보여준다. 세 버튼의 너비·높이를 통일하며, 좁은 화면에서 긴 문구는 두 줄로 표시한다. 편집 입력 영역의 파란 포커스 테두리는 제거하고 입력 커서·선택 기능은 유지한다.

입력을 시작하면 편집 상단도 페이드아웃한다. 본문 한 번 터치는 커서를 정상 이동시키면서 숨은 메뉴를 표시하며, 읽기와 달리 터치할 때마다 숨김/표시를 토글하지 않는다. 다시 입력하면 숨긴다. 스크롤·문자 선택·확대 조작은 메뉴 호출과 구분한다. 외부 키보드 Escape로도 숨은 메뉴를 표시할 수 있다.

| 행동·상태 | 확정 동작 |
|---|---|
| 변경 없음 | 저장만 비활성화. 회색 글자·강조 배경 없음·터치 차단 |
| 변경 있음 | 저장 활성화. 되돌리기로 마지막 저장 상태와 같아지면 다시 비활성화 |
| 다른 이름으로 저장 | 정상 문서에서 항상 활성화. 내용 변경 없이 이름·폴더만 바꿔 저장 가능 |
| 저장 누름 | “저장하시겠습니까?”와 아니오 / 예 |
| 아니오 | 변경 내용 유지, 편집 계속 |
| 예·저장 성공 | 현재 문서에 저장, 편집 유지, 저장만 비활성화 |
| 저장 실패 | 원본·편집 내용을 보존하고 실패 이유·다른 위치 저장 등 다음 행동 제공 |
| 취소 | 마지막 저장 이후 미저장 변경을 버리고 열람으로 복귀. 취소에 별도 설명 팝업을 추가하지 않음 |
| 시스템 종료·뒤로 등 별도 이탈 | 플랫폼·문서 엔진 통합 시 미저장 보호를 별도 검증 |

다른 이름으로 저장은 이름·위치 지정 화면 자체의 저장 버튼으로 확정하며 일반적인 추가 저장 확인창은 생략한다. 같은 이름의 기존 파일을 바꾸는 경우에는 대상 이름·폴더와 덮어쓰기 여부를 확인한다. 성공 후 새 파일에서 편집을 이어가고 원본은 보존한다.

실행 취소/다시 실행은 엔진의 트랜잭션·서식 복원 지원을 검증한 뒤 연결한다. 시안은 외부 키보드 Ctrl+Z / Ctrl+Shift+Z로 예시 텍스트 변경을 되돌릴 수 있다. 이것이 rhwp의 실제 표·서식 편집 취소 지원을 증명하지는 않는다. 모바일 편집 엔진이 지원하는 선택·편집 메뉴를 검토하되 상단 세 버튼 구성은 유지한다.

실제 저장은 F12/F13 개선을 전제로 한다. 임시 파일 작성 → 결과 형식·재열기 검증 → 가능한 파일시스템에서 원자적 교체 → 성공 확인 후 임시 정리 순서를 따른다. 문서 공급자가 원자적 교체를 지원하지 않는 경우 복구 가능한 백업·실패 처리를 별도 구현한다. 원본부터 삭제하는 방식은 금지한다. HWPX도 결과 재검증을 생략하지 않는다.

## 7. 다른 이름·PDF 저장

저장 화면은 저장 위치, 파일 이름, 고정된 확장자, 취소·저장으로 구성한다. 기본 위치는 현재 문서의 로컬 폴더를 사용하고, 접근할 수 없으면 마지막 유효한 로컬 위치 등을 안내한다. 기본 이름은 현재 이름으로 넣고 확장자를 제외한 본문 이름만 선택해 둔다. 이름이 길면 입력창 안에서 편집할 수 있다.

다른 이름으로 저장은 원래 확장자를 유지한다. PDF 저장은 .pdf를 미리 지정하고 동일한 위치·이름 흐름을 사용한다. PDF는 기기 안에서 생성하며 기존 시스템 인쇄·외부 공유·클라우드 공급자로 위임하지 않는다.

이름의 빈 값, 경로 구분자·제어 문자, . 및 .., 실제 대상 파일시스템의 이름 길이 제한을 검사한다. 한글·공백·정상 특수문자를 일괄 금지하지 않는다. UTF-8 바이트와 공급자 제한을 고려하며 시안의 255바이트는 예시 제한이다. 실패 시 입력값·선택 위치를 유지하고 문제가 있는 항목 옆에 이유를 표시한다.

같은 이름이 있으면 바꾸기 / 이름 바꾸기를 제공한다. 현재 문서와 같은 경로·이름을 다른 이름으로 저장하려는 경우 일반 저장을 안내하거나 다른 경로·이름 선택을 요구해 의미를 분명히 한다. 문서 열기 이후 원본이 외부에서 바뀌었다면 자동 덮어쓰지 않고 충돌을 안내한다.

실제 앱에서는 쓰기 가능한 로컬 폴더를 탐색·지정할 수 있어야 한다. 시안의 고정 예시 폴더 목록은 Android 파일 선택기 구현을 대신하지 않는다. 공급자·URI가 로컬인지 검증하고, 다른 이름/PDF 저장에서 선택 취소하면 문서로 돌아간다.

## 8. 오류·경계 상황의 기준

| 상황 | 사용자에게 보일 결과·처리 |
|---|---|
| 권한 없음 | 문서가 없다는 문구 대신 허용 이유와 새로고침 안내 |
| 실제 문서 0개 | 한글 문서 없음, 저장 위치 확인·새로고침 안내 |
| 검색 결과 0개 | 검색 결과 없음, 검색어 수정·지우기 |
| 즐겨찾기 0개 | 별을 눌러 추가하는 방법 |
| 긴 이름·동일 이름 | 두 줄 이름·확장자, 폴더 구분, 전체 정보 접근 |
| 많은 문서 | 목록 우선, 비동기 미리보기, 작업 중 상호작용·중지 |
| 파일 이동·삭제 | 목록에서 상태 갱신, 찾을 수 없음과 새로고침 안내 |
| 권한 철회 | 실제 상태 확인, 허용 안내, 편집 내용 보존 |
| 암호 문서 | 암호 입력·보호 상태 구분, 평문 썸네일·복구 캐시 금지 |
| 손상·지원하지 않는 문서 | 열 수 없는 이유, 원본 유지, 범위가 정해진 재시도 |
| 과대 파일·압축 폭탄 | 파싱 전/중 자원 상한, 취소, 앱 전체 중단 방지 |
| 저장 공간 부족 | 원본·미저장 내용 유지, 공간 확보 또는 다른 위치 저장 |
| 읽기 전용·SD 제거 | 해당 경로 저장 중지, 다른 로컬 위치 선택 |
| 파일 이름 충돌 | 대상 이름·폴더 표시 후 바꾸기/이름 바꾸기 |
| 외부 수정 충돌 | 변경된 원본을 자동 덮어쓰지 않고 새 이름 저장 제안 |
| 화면 회전·분할창·키보드 | 편집·커서·스크롤 보존, 버튼과 입력 필드 가림 방지 |
| 큰 글씨·좁은 화면 | 버튼 줄바꿈·높이 증가, 잘림 방지, 최소 48dp 터치 영역 |
| 종료·프로세스 종료 | 가능한 경우 기기 내부 복구; 보호 문서는 평문으로 남기지 않음 |
| PDF 생성 실패 | 편집 내용 유지, 이유·재시도/다른 위치 안내 |
| 썸네일 생성 실패 | 목록·열람 계속 허용, 파일 아이콘으로 대체 |

표의 Android·파일 엔진 실패 상황은 요구사항이며 실제 동작 검증 완료를 뜻하지 않는다. 시안은 권한 거절, 검색 결과 없음, 긴 이름·중복 이름, 즐겨찾기 없음, 잘못된 이름·길이 초과, 이름 충돌, 미저장 이탈을 직접 확인할 수 있다.

## 9. 전경 확인·보관·접근성

앱 복귀 시 전경에서 변경된 파일만 조용히 확인한다. 사용자 스크롤·터치·편집 중 목록 순서를 바꾸지 않고 안전한 시점에 반영한다. 상시 백그라운드 스캔·자동 앱 실행·주기 서비스는 사용하지 않는다. 시안의 예시 문서는 외부에서 바뀌지 않으므로 실제 증분 스캔은 엔진 통합 후 검증한다.

즐겨찾기·읽던 위치·정렬·테마는 앱 전용 로컬 저장소에만 기록한다. 문서 내용·경로·썸네일은 외부로 전송하지 않는다. 공유용 캐시를 제거한다. 미리보기 캐시는 접근 제한·용량 상한·삭제 정책을 적용하고 암호 문서는 보호 원칙을 지킨다.

모든 실제 앱 터치 영역은 최소 48dp를 목표로 한다. 작은 별·X도 누를 수 있는 영역을 넓힌다. 버튼 이름·선택 상태·오류를 접근성 서비스에 전달한다. 아이콘만으로 의미를 전달하지 않는다. 문서 집중 모드의 숨은 메뉴는 포커스되지 않는다. 시안은 모달 안의 키보드 포커스를 유지하고 Escape로 닫을 수 있다.

## 10. 검증과 남은 구현

이번 시안은 예시 문서에 대한 폴더 선택 화면이 열린 상태에서 시작한다. 취소하면 문서함으로 돌아간다. 실제 Android 권한을 얻거나 사용자 파일을 읽지 않는다. 최초 설치 권한 흐름은 4절의 기준을 유지한다. Chromium 133에서 아래 흐름을 확인했고 스크립트 오류·외부 네트워크 요청은 없었다.

- 보기 전환 한 버튼·아이콘/이름 전환·두 보기 순환
- 문서함 상시 세로 바·스크롤 위치 연동·손잡이 드래그
- 새로고침 완료/중지 팝업 없음
- 읽기 상단 소형 연필 아이콘·PDF 버튼 제거·페이드 후 상단 여백 제거
- 스크롤된 문서의 본문 위치 보정
- 편집 페이드 여백 제거·기존 취소/저장 확인 유지
- 길게 누르기 메뉴 4항목·문서 열기 억제·닫기
- 문서 카드 드래그 시 길게 누르기 취소
- 마우스 메뉴·즐겨찾기 즉시 반영·화면 팝업 없음
- 팝업 즐겨찾기 제거·파일 이동 경로 선택·이름/별/문서 개수 유지
- 이동 대상 이름 충돌 시 원래 위치/기존 파일 보존
- 이동 취소 시 위치 유지·재실행 후 이동 위치 기억
- 파일 이름 변경·확장자 유지·잘못된 이름 검증
- 길게 누르기 메뉴에서 PDF 이름/경로 선택·목록 복귀
- 메뉴 파일 정보의 긴 이름/경로 표시
- 폴더 목록 탐색·상위 경로·현재 위치 표시
- 현재 폴더 검색·검색 결과 없음·정렬
- 새 폴더 생성·잘못된 이름/중복 검사·생성 폴더로 이동
- 새 폴더/이동 위치 로컬 기억·저장공간 전환
- 320/390/736px·밝음/어두움·긴 이름·메뉴/열람/편집 넘침 없음

문서함의 상시 스크롤바는 구현했다. 문서 내부의 오른쪽 빠른 페이지 탐색 바와 두 손가락 확대/축소(최소 너비 맞춤 100%)는 앞선 검토안이며 이번 시안에 구현하지 않았다. 실제 페이지 엔진·다중 터치·키보드·문자 선택과 함께 검증해야 한다. 실제 Android TalkBack·시스템 글자 크기·저장장치·손상 문서·서식 보존도 별도 시험 대상이다.

실제 앱 0.1.0에서 바뀐 상태는 0절을 참고한다. 설치 빌드와 엔진·파일 처리 코드는 제공했으며 남은 완료 검증은 Android 실기기 오프라인 사용, 권한 철회·SD 분리·공간 부족·회전·키보드·TalkBack·큰 글씨·실제 PDF와 다양한 문서의 서식 보존이다. 기존 파일 덮어쓰기 확인, 암호 입력, 편집 초안 복구와 전경 증분 파일 갱신은 이 초기 버전의 범위에 포함하지 않았다.

원본 APK의 저장 결함과 원격 경로 자체는 수정하지 않았다. 제공하는 설치 APK는 새 패키지의 별도 앱이며 실기기 검증을 마친 배포본이라고 해석해서는 안 된다.
